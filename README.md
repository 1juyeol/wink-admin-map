# 🗺️ 윙크 어드민 관리 (Wink Admin Map)

이 프로젝트는 윙크 서비스의 지도 데이터 및 관리자 기능을 위한 React 기반 웹 애플리케이션입니다.

## 🚀 프로젝트 개요
- **기술 스택**: React, Vite, Firebase, TailwindCSS
- **주요 기능**: 
  - 지도 기반 데이터 시각화 및 관리
  - 서비스 운영을 위한 관리자 대시보드
  - 실시간 데이터 동기화 (Firebase 연동)

## 🛠️ 개발 가이드
### 로컬 실행
```bash
npm install
npm run dev
```

### 배포 (Firebase Hosting)
```bash
npm run build
firebase deploy
```
